# P0–P3优化运行手册

## P0：冻结当前基线与P1诊断

三套标签明细存在时执行：

```bash
python -m src.index_enhancement.research_audit \
  --config configs/index_enhancement/default.yaml \
  --baseline-id baseline_v2_index_excess_l2_equal_weight
```

输出位于 `experiments/<baseline_id>/`，包括文件SHA256、年度/月度回测、换手成本、现金拖累、成熟标签覆盖率、日度/年度RankIC、Q5-Q1、分组单调性、Top-N目标收益和排名稳定性。若本地没有Colab生成的 `labels.pkl`，仍会冻结模型与回测，但跳过信号诊断。

## P2：多目标LightGBM

实验矩阵位于 `configs/index_enhancement/model_experiments.yaml`：

- `cross_sectional_rank`：截面Rank回归；
- `excess_huber`：Huber超额收益回归；
- `excess_top_weighted`：最高20%样本三倍权重；
- `lambdarank`：每日股票为一个ranking group；
- `excess_l2`：旧基线。

单独运行Rank和LambdaRank：

```bash
python -m src.index_enhancement.model_experiments \
  --experiments cross_sectional_rank,lambdarank
```

输出位于 `results/index_model_experiments/<experiment>/<index>/`。每个滚动窗口保存一个 `lgbm_window_NNN.joblib`，并继续保存最后模型、预测、指标和重要性。

## P3：三指数独立AlphaEval

```bash
python -m src.alpha_eval.run_index_evaluation \
  --config configs/daily/training.yaml \
  --target-column target_excess_return
```

输出：

```text
results/index_alpha_eval/
├── manifest.json
├── csi300/alpha_eval_result.csv
├── csi300/selected_factors.csv
├── csi500/...
└── csi1000/...
```

每个指数只使用训练期历史成分、可交易的指数超额标签和该Universe内因子值。LightGBM实验入口会优先读取对应指数的筛选结果；文件不存在时才降级使用全市场AlphaEval结果。

## Colab一体化流程

`notebooks/pipelines/daily_colab_a100.ipynb` 已按以下顺序更新：

```text
全市场GFlowNet
→ 全市场初筛
→ 三指数标签
→ 三指数独立AlphaEval/DPP
→ 默认cross_sectional_rank三指数LightGBM
→ 保存全部滚动模型
→ 打包下载
```

需要切换实验时修改Notebook中的：

```python
INDEX_MODEL_EXPERIMENT = 'cross_sectional_rank'
```

可替换为 `excess_huber`、`excess_top_weighted` 或 `lambdarank`。不同实验必须使用独立输出目录或及时归档，禁止覆盖后再比较。
